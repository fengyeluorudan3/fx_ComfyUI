# Resource Directory

This directory contains:
- **fx_agent_core-0.1.1.tar.gz** - Agent core package
- **fx_lang_ex-0.1.1.tar.gz** - Language extension package

## Installation

```bash
pip install resource/fx_agent_core-0.1.1.tar.gz resource/fx_lang_ex-0.1.1.tar.gz
```

## Usage in Docker

The Dockerfile automatically installs these packages during the build process.
